Sign, send, report

import { Connection, VersionedTransaction } from "@solana/web3.js";

const api = "https://api.stoker.markets/v1";
const prepared = await (await fetch(`${api}/trades/prepare`, {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({ mint, trader: wallet.publicKey.toBase58(), side: "buy", amount: "100000000", slippageBps: 100 }),
})).json();

const tx = VersionedTransaction.deserialize(Buffer.from(prepared.transaction, "base64"));
tx.sign([wallet]);
const connection = new Connection(rpcUrl, "confirmed");
const signature = await connection.sendTransaction(tx);
await connection.confirmTransaction({ signature, blockhash: tx.message.recentBlockhash, lastValidBlockHeight: prepared.lastValidBlockHeight }, "confirmed");
await fetch(`${api}/transactions/${signature}`, { method: "POST" });

Errors

400
The body or query isn't what the contract asks; details lists each issue.
401
An unknown or revoked key.
403
An airdrop from a wallet not allowed one.
404
No such coin, asset, round or key.
409
A name, ticker or image a protected coin already has.
422
Well-formed, but not admissible: an asset the curve rules don't admit at today's price, or a SOL buy with no route.
429
Past a rate limit; retry-after says how long to wait.
500, 503
Ours, or a dependency down for the moment. Try again in a minute.
