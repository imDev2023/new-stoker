# new-stoker

The rebuild of Stoker, the open, asset-paired Solana launchpad on Raydium LaunchLab, in a repository of its own.
It began as a copy of [imDev2023/Stoker-Markets](https://github.com/imDev2023/Stoker-Markets) on 2026-11-04, history included; the original stays as the fallback and still deploys the live API.

- The plan, every decision and the order of the work: [issue #1, the map](https://github.com/imDev2023/new-stoker/issues/1).
- The site is rebuilt from scratch in the Playground's design: [ADR 0017](docs/adr/0017-the-site-rebuilt-in-the-playground-design.md), with the spec in [docs/design/playground](docs/design/playground/SOURCE.md).
- Programs of our own are allowed: [ADR 0018](docs/adr/0018-custom-on-chain-programs.md).
- How to run, test and work here: [CLAUDE.md](CLAUDE.md).
